# 第 34 课：长期坚持的心理建设

> **本课只解决的问题**：面对回撤和诱惑，如何保持纪律？如何建立长期主义心态？  
> **预计时间**：40–60 分钟。  
> **本课不做什么**：不提供"战胜人性"的神奇方法，只提供实用的心理工具。

> **本课行动边界**  
> - 心理建设不是一次性完成，需要在实盘中反复练习和强化。  
> - 如果发现自己真的无法承受配置的波动，降低风险暴露是正确选择。  
> - 投资不应影响生活质量，焦虑失眠时应立即调整配置或暂停。

## 先想：什么会让你放弃？

回顾你在前面课程中设计的配置（假设平衡型：股 50% + 债 35% + 现金 15%）。

**场景 1：市场持续下跌**
- 你买入后，市场连续 6 个月下跌。
- 账户从 10 万跌到 8.5 万（-15%）。
- 新闻充满悲观论调："经济衰退""熊市才刚开始"。
- 你会：
  - □ 坚持定投，甚至加大金额（逆向思维）
  - □ 继续按计划定投，不增不减（纪律）
  - □ 暂停定投，观望一段时间（择时）
  - □ 全部卖出止损（恐慌）

**场景 2：市场持续上涨，但你踏空**
- 你还在慢慢定投，市场已经涨了 30%。
- 朋友炫耀："我全仓买入，已经赚了 50%。"
- 社交媒体充满"牛市来了""不上车就晚了"。
- 你会：
  - □ 坚持配置，按计划定投（纪律）
  - □ 把债券和现金全换成股票（追涨）
  - □ 暂停定投，觉得"买不起了"（择时）
  - □ 后悔没有早点全仓，情绪低落（FOMO）

**场景 3：你的配置跑输朋友**
- 你年化收益 8%，朋友炒股赚了 50%。
- 你开始怀疑："我是不是太保守了？""配置有什么用？"
- 你会：
  - □ 坚持配置，理解短期结果不代表长期（理性）
  - □ 调整配置，增加激进度（动摇）
  - □ 放弃配置，学朋友炒股（盲从）

**思考**：以上场景哪个最容易让你放弃纪律？

## 长期坚持的五个心理工具

### 工具 1：预期管理——接受波动是常态

**错误预期**：
- "我配置合理，应该每个月都赚钱。"
- "我定投了，股市就不应该跌。"

**现实**：
- 即使配置合理，短期（1–3 年）仍可能亏损。
- 股市每年有 40%–50% 的交易日是下跌的。
- 历史上沪深 300 约每 3–5 年经历一次 -20% 以上回撤。

**预期调整**：
- 把 -15% 至 -20% 回撤视为"正常波动"，而非"严重错误"。
- 亏损不等于失败，只是还没到盈利的时候。
- 5–10 年尺度看，才能判断配置成功与否。

**练习**：在本子上写下：

```
我的配置在未来 5 年可能出现：
- 最好情况：年化 +12%，5 年总收益约 +76%
- 正常情况：年化 +8%，5 年总收益约 +47%  
- 最差情况：5 年累计亏损 -10%，但第 6–10 年恢复盈利

我接受这些可能性，并承诺不因短期波动改变配置。
```

### 工具 2：注意力管理——减少查看频率

**问题**：频繁查看账户增加焦虑。

研究表明：
- 每天查看账户的投资者，焦虑水平是每月查看者的 3 倍。
- 焦虑导致更多情绪化操作（追涨杀跌）。
- 情绪化操作降低长期收益约 2%–4%/年。

**建议查看频率**：

| 投资阶段 | 建议频率 | 原因 |
| --- | --- | --- |
| 刚开始投资（前 3 个月） | 每周 1 次 | 熟悉波动，建立心理预期 |
| 正常投资（3 个月后） | 每月 1 次 | 记录资产和执行定投 |
| 成熟投资者（1 年后） | 每季度 1 次 | 只关注再平衡和年度复盘 |

**操作建议**：
- 删除基金 App 首页快捷方式（增加打开难度）。
- 关闭持仓盈亏推送通知。
- 设置固定查看日（如每月 1 号），其他时间不看。

### 工具 3：对比锚点——选择正确的参照系

**错误对比**：
- 和炒股赚 50% 的朋友比 → 感到配置"收益太低"。
- 和牛市顶点的账户市值比 → 感到当前"亏太多"。

**正确对比**：

| 对比对象 | 你的思考 |
| --- | --- |
| 你的初始本金 | 是否在增长？即使慢也是进步 |
| 活期存款收益（0.3%） | 配置是否跑赢存款？ |
| 同期沪深 300 涨跌 | 配置是否降低了波动？ |
| 通胀率（2%–3%） | 配置是否跑赢通胀？ |

**心理话术**：
- "朋友炒股赚 50% 很好，但我看不到他亏损 -30% 的时候。"
- "我的配置虽然慢，但让我睡得着觉，这本身就是价值。"
- "我在用 5–10 年维度赚钱，不和短期投机比。"

### 工具 4：过程导向——关注行动而非结果

**结果导向（有问题）**：
- "我今年赚了 15%，说明我做对了。"
- "我今年亏了 -10%，说明我做错了。"

**问题**：
- 短期结果有运气成分（如赶上牛市、避开股灾）。
- 结果导向容易在亏损时自我否定，在盈利时过度自信。

**过程导向（推荐）**：

| 关注点 | 自我评估 |
| --- | --- |
| 是否按计划定投？ | ✓ 12 个月全部执行 |
| 是否按计划再平衡？ | ✓ 年度执行 1 次 |
| 是否避免追涨杀跌？ | ✓ 0 次择时操作 |
| 是否记录和复盘？ | ✓ 每月记录 |

**心理话术**：
- "今年亏了 -10%，但我坚持了纪律，过程是对的，长期会看到结果。"
- "朋友今年赚 50%，但他是运气还是能力？他明年还能赚吗？"

### 工具 5：反脆弱性——从波动中获益

**脆弱心态**：
- "股市跌了，我的计划失败了。"
- "定投买贵了，亏大了。"

**反脆弱心态**：
- "股市跌了，我的定投在低位买入更多份额，未来收益会更高。"
- "回撤是建仓机会，不是失败。"

**实践**：
- 市场跌 -10%：庆祝"打折季"，坚持定投。
- 市场跌 -20%：如果有额外资金，考虑加大定投（不超出承受范围）。
- 市场涨 +30%：提醒自己再平衡，卖高买低。

## 四个心理陷阱与应对

### 陷阱 1：损失厌恶

**表现**：亏损 1 万的痛苦 > 赚 1 万的快乐（约 2.5 倍）。

**影响**：
- 亏损时不敢割肉（"等回本再说"），结果亏更多。
- 盈利时急于止盈（"落袋为安"），错过长期收益。

**应对**：
- 提醒自己：账面亏损不是真亏损，只是暂时的。
- 只有在配置逻辑改变（如风险承受能力下降）时才调整，不因短期亏损调整。

### 陷阱 2：确认偏误

**表现**：只看支持自己观点的信息，忽略相反证据。

**影响**：
- 买入某基金后，只看利好消息，忽视风险。
- 坚持错误决策，因为不愿承认判断失误。

**应对**：
- 每次复盘时，主动寻找反面证据："有什么理由说明我错了？"
- 记录决策时的完整逻辑（包括风险），定期检验。

### 陷阱 3：锚定效应

**表现**：以买入价格为"锚点"，影响后续决策。

**影响**：
- 买入后跌 -20%，觉得"等回本再卖"（实际回本可能遥遥无期）。
- 买入后涨 +50%，觉得"跌回去就买"（实际再也回不去）。

**应对**：
- 忘记买入价格，只关注当前配置是否合理。
- 每次决策时问："如果今天重新开始，我还会这样配置吗？"

### 陷阱 4：羊群效应

**表现**：看到别人买就买，看到别人卖就卖。

**影响**：
- 追热点高位接盘（如 2015 年杠杆牛市、2021 年新能源泡沫）。
- 恐慌性抛售低点割肉（如 2020 年 3 月新冠暴跌）。

**应对**：
- 提醒自己："市场是少数人赚多数人的钱。"
- 大多数人做的事，通常不是最优解。

## 实操任务：建立你的心理预案

### 预案 1：市场大跌时

如果我的账户回撤超过 -15%，我会：

1. 暂停查看账户（从每月改为每季度）。
2. 重新阅读第 9 课（最大回撤）和第 10 课（风险承受能力）。
3. 检查配置是否偏离目标，如果没有，坚持不动。
4. 如果焦虑到失眠，考虑永久降低股票占比（不是暂时清仓）。
5. 提醒自己：历史上每次大跌后都有恢复，我的配置能穿越周期。

### 预案 2：市场大涨时

如果我的账户收益超过 +20%，我会：

1. 不追加股票投资，坚持原配置比例。
2. 检查股票占比是否超过目标 +10%，如果是，执行再平衡。
3. 提醒自己：大涨后通常是回调，不追高。
4. 庆祝盈利，但不改变长期计划。

### 预案 3：看到他人暴富时

如果朋友炒股/炒币赚 50%+，我会：

1. 祝贺他，但不跟风。
2. 提醒自己：我看不到他亏损的时候，也不知道他能否持续。
3. 回顾我的配置逻辑和风险承受能力，确认不改变。
4. 接受"我的收益可能更低，但我睡得着觉"。

## 核心要点

- 长期坚持需要五个工具：预期管理（接受波动）、注意力管理（减少查看）、对比锚点（选对参照）、过程导向（关注行动）、反脆弱（从波动获益）。
- 四个心理陷阱：损失厌恶、确认偏误、锚定效应、羊群效应，需要提前识别和应对。
- 建立心理预案：市场大跌时如何应对，市场大涨时如何应对，看到他人暴富时如何应对。
- 如果投资影响睡眠和生活质量，立即降低风险暴露，不要硬撑。
- 投资是马拉松而非短跑，坚持纪律比追求高收益更重要。
