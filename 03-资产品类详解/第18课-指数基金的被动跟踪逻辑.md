# 第 18 课：指数基金的被动跟踪逻辑

指数基金看起来像"跟着指数走"，实际上还要面对复制方式、调仓、费用和跟踪误差这些环节。本课沿着"指数到基金净值"这条链条，逐段检查它到底怎么运作。

## 指数基金是什么

**指数基金**是一种**被动管理**的基金，目标是复制某个指数（比如沪深300、中证500）的表现。经理不主动选股，只按指数的成分股和权重买入；指数调整成分股时，基金也跟着调整。

打个比方：你想买一篮子水果，但不想自己挑。于是找到一个"水果指数"——它规定了这篮水果的品种和比例，比如一半苹果、三成香蕉、两成橙子。你照这个比例买就行，不管哪种水果更新鲜更便宜。指数基金就是这个逻辑：不做主观判断，只复制一套规则。

## 和主动股票基金的区别

| 比较项 | 主动股票基金 | 指数基金 |
| --- | --- | --- |
| 选股方式 | 经理主动选股 | 被动复制指数成分股 |
| 调仓频率 | 较高，随市场调整 | 较低，只在指数调整时动 |
| 管理费率 | 较高（常 1.5% 每年上下） | 较低（常见约 0.5%–1%） |
| 业绩目标 | 想跑赢指数 | 只想贴近指数 |
| 对经理的依赖 | 大，业绩看经理功力 | 小，只需执行复制规则 |
| 透明度 | 较低，持仓每季公布 | 较高，成分股实时透明 |

一句话浓缩差异：主动基金想跑赢市场，指数基金只求跟上市场。

## 为什么它做不到百分之百跟上指数

指数基金的目标是"贴近"，但实际收益通常比指数略低一点，原因有四处：

1. 管理费和托管费。指数基金每年收管理费和托管费，这部分会被从净值里扣掉。
2. 跟踪误差。指数调整成分股时，基金要跟着买卖，会产生交易成本；大手笔买入可能推高价格、卖出可能压低价格，这种"冲击成本"累积下来就是偏差。
3. 现金留存。基金要留一部分现金来应对申赎，这部分现金几乎不产生收益，会拖慢整体表现。
4. 停牌或涨跌停。成分股出了意外停牌、或到涨跌停时，基金没法及时同步调整。

最终，这些成本加在一起，就形成我们常说的"基金跑不过指数一点点"。

## 指数基金的好处

它最大的价值是**低费用**——管理费常只有主动基金的一半甚至三分之一，长期滚下来差别非常大。其次是**高透明**，成分股和权重公开，你随时知道它手里有什么。再就是**分散**，指数通常包含几十只乃至几百只股票，单只股票暴跌对净值的冲击被摊得很小。还有一点：不依赖某个经理，经理辞职了基金照样按规则走，业绩不会因为换人而大变。

## 它的风险也一样在

指数基金只是把"选股的风险"卸下来了，但市场风险一分没少，甚至没法靠选股去躲。

**市场风险。** 指数跌，基金就跟着跌。比如 2018 年沪深300 下跌约 25%，跟踪它的指数基金大致也跌 25%。这一点和主动股票基金一样，你买指数基金，等于明明白白接下整个市场的起落。

**跟踪误差风险。** 上面说的交易成本、现金留存、停牌影响，会让实际收益偏离指数，差一点还是差很多，要看基金做得好不好。

**费用损耗。** 管理费和托管费每日从净值扣，长期累积会让实际收益低于指数本身。

**行业集中风险。** 有的指数集中在特定行业，比如科技主题指数。这种指数遇到整个行业衰退时，风险比宽基指数大得多，买之前得先看懂它到底装着什么。

**上限就是"贴近"。** 指数基金只能无限靠近指数，因为有了费用和跟踪误差，几乎不可能一路"跑赢"指数。所以，如果你认为自己能持续挑出跑赢市场的经理或标的，指数基金自然不是你的第一选择；但对多数不想折腾的普通人来说，它"跟上市场、成本更低"的特点反而是长期更省心的路子。

## 值得记住的几件事

1. 指数基金被动复制指数成分股，不靠人选股，费用低、透明度高。
2. 它的收益通常略低于指数，因为管理费、托管费和跟踪误差会在每一点上慢慢扣除。
3. 它主要暴露在所跟踪指数的市场风险之下，还有跟踪误差、费用损耗等额外成本，无法靠选股躲开市场下跌。
4. 适合相信市场长期向上、又不愿依赖选股能力的长期投资者。
