# 第 21 课：费用如何影响长期结果？

费率通常不会在账户里单独跳出来，却会悄悄地从你的长期结果里扣掉一小部分。本课用同一组收益假设，看管理费、交易成本和复利是怎样叠在一起起作用的。

## 先把费用分成两类

基金的收费，大体能分成一次性费用和持续性费用，记错类型，长期判断就会跑偏。

**一次性费用，买卖时收。** 申购费是买入时一次扣掉的，赎回费是卖出时扣的，赎回费往往随持有时间变长而递减。同一只基金常分 A 类和 C 类：A 类收申购费、不设销售服务费，C 类相反，没有申购费但日常计提销售服务费。这为后面选择留了个伏笔。

**持续性费用，每天都在扣。** 管理费付给基金公司，是基金"吃饭"的钱；托管费付给托管银行，用来保管资产；销售服务费是 C 类基金特有的，付给销售渠道。这几笔都不是从你口袋里先掏出来，而是每天从净值里扣除——所以你在净值数字里通常"看不太见"它们，但它们确实一直在起作用。

除此之外，还有一类隐性成本：基金买卖股票、债券时产生的佣金和印花税，以及大额买卖时冲击价格带来的损失。这些不直接出现在费率表里，但同样侵蚀收益。

## 一个例子看费用如何吃掉收益

假设你投 10,000 元进一只股票基金，基金按年化 10% 增长，持有 10 年。

先看没有费用的理论值：期末资产约等于 10,000 × (1.1)^10 ≈ 25,937 元。

再算上费用：买入时扣掉申购费后实际投入约 9,985 元；此后每年管理费加托管费大约 1.75% 从净值里扣，实际年化净收益降到约 8.25%，期末资产约为 9,985 × (1.0825)^10 ≈ 22,087 元。

两者一对比，费用整整吃掉了约 3,850 元，占了理论收益（15,937 元）的大约四分之一。这还只是十年的差距，时间拉得越长，复利作用下这个差距会被放大得越厉害。换句话说，费率低一点，长期看可能不是"省一点"，而是"差一大块"。

## A 类与 C 类，什么时候谁更划算

A 类和 C 类的差别，最后往往落到"你打算拿多久"上。摆成一张表最清楚：

| 比较项 | A 类 | C 类 |
| --- | --- | --- |
| 申购费 | 有（买时一次收） | 无 |
| 赎回费 | 有，随持有时间递减 | 有，随持有时间递减 |
| 销售服务费 | 无 | 有，每年计提 |
| 更划算的持有时长 | 长期（比如一年以上） | 短期（一年以内） |

用一组明确数字就能看出差别。假设某基金 A 类申购费 0.15%、C 类销售服务费每年 0.4%，各投 10,000 元：

持有 6 个月时，A 类要付申购费加赎回费，C 类付半年销售服务费加赎回费，两家总费用很接近（几乎打平，具体可退回前面数的前面算一遍）。

可一旦持有 3 年，情况就分化了：A 类只是买时一次性的那点申购费；C 类的销售服务费却要按年计提三年，越攒越多，明显高于 A 类。所以规律很简单——打算长期拿，A 类更省；只打算短期周转，C 类更灵活。前提是你提前知道自己的持有期限，别等到要卖时才想起赎回费那道坎。

## 不同基金类型的费用差异

不同类型基金的收费标准差别不小，但要特别提醒一点：**单品费率会在各家、各产品之间浮动，也会随市场与监管调整，不存在写死的"恒定值"**。下面只是大致量级的参考，用来帮你建立"谁贵谁便宜"的印象，具体买入前务必以当期的基金招募说明书为准。

通常的印象是这样：主动股票基金管理费最高；指数基金因为是被动复制，管理费用拼低不少；ETF 场内没有申赎费，只有券商佣金加日常的管理托管费，综合看常常是最省的一类。长期拿着不动时，这类费用优势会稳定地累积下来——这正是上一课"指数基金和 ETF 适合长期投资者"的重要原因。

## 值得记住的几件事

1. 基金费用分一次性（申购费、赎回费）和持续性（管理费、托管费、销售服务费）两类。
2. 持续性费用每天从净值里扣，你不一定能直接看见，但它们长期累积影响很大——1.75% 的年费，十年能吃掉约四分之一的理论收益。
3. A 类适合长持、C 类适合短持，关键看你的持有期限，而不是看某一只看起来"申购费低"。
4. 不要只凭费率低就选某只基金，跟踪误差、流动性这些同样影响最终结果，更不要忽视那些"每天悄悄在扣"的持续性费用。
