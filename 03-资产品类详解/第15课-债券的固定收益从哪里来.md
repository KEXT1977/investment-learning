# 第 15 课：债券的固定收益从哪里来？

> **本课只解决的问题**：买债券时，资金借给了谁？约定的利息为什么不等于确定收益？  
> **预计时间**：45–60 分钟。  
> **本课不做什么**：不推荐具体债券、债券基金或交易渠道，不根据票面利率判断是否值得购买。

> **本课行动边界**  
> - 只观察债券资料与现金流，不开户、认购或交易债券。  
> - “固定收益”描述的是约定的付息规则，不是本金和收益的保证。  
> - 在不理解发行人、期限、信用与价格风险前，不用单一利率作决定。

## 先做：观察一份债券要素表

在公开债券信息页面、基金持仓报告，或课程提供的虚构案例中，找一只债券并记录以下信息。看不懂的字段可以填“待查”，不要自行猜测。

| 要素 | 你看到的内容 | 它回答的问题 |
| --- | --- | --- |
| 发行人 |  | 谁在向投资者借钱？ |
| 债券类型 |  | 是政府、金融机构还是企业发行？ |
| 面值 |  | 到期时每份约定归还多少本金？ |
| 票面利率 |  | 按面值约定支付多少利息？ |
| 到期日 |  | 借款关系约定何时结束？ |
| 付息方式 |  | 利息按年、半年还是到期一次支付？ |
| 信用评级（如有） |  | 独立评级机构如何评估其偿债能力？ |

**债券**可以先理解为一份可交易的借条：发行人向投资者借钱，并约定利息、还本时间与其他条件。持有人不是发行人的股东，通常不参与经营决策；其优先关心的是发行人能否按约付息和还本。

## 债券的现金流怎样形成？

债券最常见的两笔现金流是：

1. **利息**：发行人按约定频率支付。例如面值 1,000 元、票面利率 3%、每年付息一次的债券，一年约支付 30 元利息。
2. **本金**：债券到期时，发行人按约定偿还面值。上例若正常到期，持有人收到 1,000 元本金。

用最简化的虚构例子看三年的现金流：

| 时间 | 发生什么 | 持有人收到的现金流 |
| --- | --- | ---: |
| 买入时 | 以 1,000 元买入面值 1,000 元的债券 | -1,000 元 |
| 第 1 年末 | 发行人支付 3% 利息 | +30 元 |
| 第 2 年末 | 发行人支付 3% 利息 | +30 元 |
| 第 3 年末 | 支付最后一次利息并归还本金 | +1,030 元 |

这个例子只在三个条件同时满足时成立：你以面值买入、一直持有到期、发行人按时履约。真实债券价格会变化，发行人也可能无法履约，因此不能把“票面利率 3%”直接理解为“必定赚 3%”。

## 两个容易混淆的利率

### 票面利率

**票面利率**是按债券面值计算、写在发行条款中的利息比例。它决定约定利息金额，不会因二级市场价格每日变动而改变。

### 到期收益率

**到期收益率**是按当前买入价格、未来全部利息与到期本金推算出的年化回报率。它会随市场价格变化。

假设仍是一只面值 1,000 元、每年利息 30 元、尚有一年到期的债券：

| 当前买入价格 | 到期时收到 | 结果的直观解释 |
| ---: | ---: | --- |
| 1,000 元 | 1,030 元 | 回报约为 3%，接近票面利率 |
| 980 元 | 1,030 元 | 除利息外还可能有 20 元价差收益，收益率高于 3% |
| 1,020 元 | 1,030 元 | 虽有利息，但到期本金只归还 1,000 元，收益率低于 3% |

这里忽略税费、应计利息和复利，只用于说明关系。**票面利率是条款，到期收益率是基于当前价格的估算**；二者不能混用。

## 债券会怎样亏钱？

债券的风险不只来自“利息变少”。先理解以下四种情况。

### 1. 信用风险：发行人无法履约

若发行人经营恶化、资金链断裂或违约，可能延迟付息、少还本金，甚至无法偿还。政府债、金融债和企业债的发行主体与信用基础不同，不能因为都叫“债券”就默认风险相同。信用评级是可参考的信息，不是偿还保证。

### 2. 利率风险：市场利率上升，已有债券价格可能下跌

新发行债券的利率上升后，旧债券较低的固定利息吸引力下降，其市场价格通常需要下调，才可能被买家接受。期限越长，未来固定现金流受利率变化影响的时间通常越久，价格波动往往也越明显。

这不等于“利率上升就一定亏损”：若一直持有至到期且发行人履约，面值还本的约定仍在；但中途卖出时，价格变化会转化为实际损益。

### 3. 流动性风险：想卖时未必能按预期价格卖出

部分债券交易不如股票活跃。在市场紧张或债券本身交易稀少时，可能难以迅速找到买家，或者只能接受更低价格。资金有明确短期用途时，不能仅根据到期收益率判断是否合适。

### 4. 再投资风险：未来收到的利息未必还能按原利率继续投资

债券分期付息时，收到的利息需要另行安排。若当时市场利率下降，新的投资机会可能只能提供更低收益。因此，最初看到的票面利率并不代表所有现金流最终都能以相同利率累积。

## 再做：把一只债券翻译成一句话

用你在开头记录的债券，按下面的结构写一句描述：

```text
我观察到：发行人 [名称] 向投资者借款，约定在 [到期日] 前按 [付息方式] 支付利息，票面利率为 [数值]。
我还不能据此判断：[发行人一定能偿还／中途卖出不会亏损／实际到期收益率是多少]。
我需要继续确认：[当前价格、信用资料、剩余期限、交易流动性中的具体一项]。
```

如果使用的是基金持仓中的债券，可记录“基金间接持有该债券”，不要把基金的净值表现当作这只债券的票面利率。

## 检查理解

1. 债券持有人与股票股东在“资金给谁、获得什么权利”上有什么不同？
2. 为什么票面利率 3% 的债券，按不同价格买入后，到期收益率可能不同？
3. 如果你可能在到期前使用这笔钱，除信用风险外，还需要重点确认哪两类风险？

## 核心要点

1. 债券是发行人向投资者借款的契约；典型现金流是约定利息与到期本金。
2. 票面利率决定按面值计算的约定利息，不等于按当前价格买入后的实际收益率。
3. 债券可能因信用、利率、流动性和再投资风险产生损失或低于预期的收益。
