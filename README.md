## 核心产出

通过本课程，你将获得：

1. **配置方案**：基于 10 万本金 + 月投 3,000–4,000 元的完整配置
2. **定投计划**：每月定投金额、分配比例、执行时间
3. **再平衡规则**：何时调整、如何调整
4. **记录模板**：交易记录、月度总结、年度复盘
5. **心理预案**：面对回撤和诱惑的应对策略

---

## 下一步行动

### 1. 先用模拟盘验证（1–3 个月）
- 不投入真实资金
- 按配置方案模拟买入
- 体验真实波动
- 检验纪律执行

### 2. 小额实盘练习（1–2 万元）
- 验证方案可行后
- 用小额资金实盘
- 熟悉交易流程
- 调整风险承受

### 3. 逐步加仓（3–12 个月）
- 方案运行良好后
- 逐步增加金额
- 保持定投纪律
- 定期再平衡

## 重要提醒

### ⚠️ 不要做的事

- 不要学完就全仓投入
- 不要追求短期暴利
- 不要频繁操作
- 不要盲目跟风
- 不要超出承受能力

### ✅ 应该做的事

- 先完成全部学习
- 诚实评估风险承受
- 从小额开始
- 坚持记录复盘
- 保持学习优化

---
