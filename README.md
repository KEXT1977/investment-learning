# 投资学习课程

一套面向零基础读者的投资入门课程，目标是让你从看懂行情页开始，逐步理解股票、基金、ETF、交易规则、收益风险和资产配置。

课程包含 34 个核心课，以及 3 个补充实操课：

- [从第一课开始](01-市场基础认知/第01课-股票到底是什么.md)
- [查看完整学习路线](课程总览.md)
- [学习完成后的下一步](课程完成总结.md)

## 本地运行

```bash
npm install
npm run docs:dev
```

构建静态站点：

```bash
npm run docs:build
```

## 阅读原则

课程中的公司、价格和计算结果用于解释概念，不是具体的投资推荐。交易时间、费率、适当性、账户界面和产品规则会变化；真实操作前，以交易所、基金销售机构和券商当期的官方说明为准。
