# 第 02 课：股票价格为什么会动？

> **本课只解决的问题**：同一家公司的股票，为什么今天和明天会有不同价格？  
> **预计时间**：45–60 分钟。  
> **本课不做什么**：不学 K 线、不预测明天涨跌，也不寻找“买点”。

> **本课行动边界**  
> - 只观察和记录，不开户、不充值、不真实下单。  
> - 单日涨跌、公告和新闻只用于区分事实与推测，不构成买卖理由。  
> - 在完成风险、资产类别和个人资金规划课程前，不把应急资金或存款投入风险资产。

## 先做：给一个价格快照拍照

打开你在第 01 课观察过的任意一只股票。观察对象只用来认识数据，**不表示它值得买入**。

在笔记中记录以下项目，并写下你查看的时间：

| 字段 | 你记录的内容 | 它先告诉你什么 |
| --- | --- | --- |
| 最新价 |  | 最近一笔成交对应的价格 |
| 昨收 |  | 上一个交易日收盘时的价格 |
| 今日涨跌额、涨跌幅 |  | 相比昨收，价格变了多少 |
| 今开、最高、最低 |  | 今天截至现在走过的价格范围 |
| 成交量、成交额 |  | 今天已经撮合了多少买卖 |

先别急着解释“为什么”。只问自己两件事：最新价和昨收是否相同？今天的最高价与最低价之间相差多少？

> 盘中数据会不停变化；收盘后才会固定为当天的最终结果。一次截图只能说明当时的状态，不能说明全天的结论。

## 价格不是公司的标签，而是一次次成交的结果

把股票市场想成一个持续营业的二手交易市场。

- **买方**：愿意用某个价格接手股票的人。
- **卖方**：愿意用某个价格转让股票的人。
- **报价**：买方或卖方给出的“我愿意按这个价格买／卖”的条件。
- **成交**：买方和卖方在价格、数量上匹配后，真正完成的一笔交换。

你在行情软件里看到的**最新价**，通常就是最近一笔成交的价格。它不是有人给公司贴上的永久价签，更不是公司今天突然“值这么多钱”的精确答案。

例如，卖方愿意以 20 元卖出，而有人愿意以 20 元买入，这一笔就能成交，最新价可能显示为 20 元。之后若卖方都希望至少 20.10 元才卖、买方仍愿意接受，新的成交就可能把最新价推到 20.10 元。反过来，愿意卖的人急于成交、愿意买的人变少，成交价也可能向下移动。

这就是常说的**供需**：在某一时刻，愿意卖出的数量和愿意买入的数量如何相遇。请注意，它解释的是“价格怎么形成”，不等于“价格应该涨”或“人多买一定能赚钱”。

## 为什么买卖双方会改变主意？

买卖双方不是随机按按钮，他们会根据自己对未来的判断更新报价。常见信息可以分成三层：

1. **公司层面**：收入、利润、产品、竞争、管理层、分红计划等。它们影响公司未来赚钱能力的预期。
2. **环境层面**：利率、经济景气、行业供需、政策、汇率等。它们会影响很多公司，而不只是一家。
3. **市场情绪层面**：投资者的乐观、恐慌、跟随和短期资金安排。情绪会使报价在短期内明显偏离冷静估算。

这里的**预期**，是人们对未来可能发生什么的判断。市场常常根据“结果与此前预期的差距”反应，而不只根据消息听起来是好是坏。比如一家公司的利润增长了，但如果市场此前期待的是更高增长，部分人仍可能下调愿意支付的价格。

## 用一个小案例建立直觉

假设“晴天果园”有稳定的果树和客户。多数观察者认为它未来一年能赚 100 万元，于是愿意按较高价格持有它的股票。

后来天气异常，果园公告称短期产量可能下降。即使果园的土地、树木和客户没有在当天消失，部分人对未来利润的预期已经变弱，愿意出的价格可能降低；也有人认为影响只是暂时的，仍愿意买入。新的报价不断相遇，价格因此变化。

这个案例区分了两个概念：

- **公司价值**：公司长期创造现金和利润能力的估计。它无法被一个按钮精确测出，且不同人估计不同。
- **市场价格**：此时此刻最近成交和当前报价反映出的交易价格。

短期价格可以因消息和情绪波动很大；长期看，公司的经营质量通常更重要。两者有关，但绝不相同、更不会在每天完全一致。

## 再做：用同一份数据避免一个常见误会

回到你刚才的股票页面，完成下面三个小检查。

1. 找到“今开、最高、最低、最新价”。用一句话描述：最新价位于今天价格范围的什么位置？
2. 找到“成交量”和“成交额”。**成交量**是成交的股票数量，**成交额**是成交金额；两者都大，不代表价格一定上涨，只说明交易更活跃或单笔金额更大。
3. 打开该股票的一条公开公告或新闻，只记录“发生了什么”和“发布时间”，不要写“所以必涨／必跌”。下一交易日或当日市场可能如何反应，只能观察，不能由标题直接推出。

可直接复制这张记录模板：

| 日期与时间 | 观察对象 | 最新价相对昨收 | 当日高低范围 | 我看到的信息 | 我能确认的事实 | 我不能据此断言的事 |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |

最后一列很重要。例如，“公司发布业绩预告”是事实；“股价一定会上涨”则是未经验证的推测。把两者分开，是以后分析市场的基本习惯。

## 检查理解

1. 某股票今天上涨 3%，能否仅凭这一个数字断定公司价值也上涨了 3%？为什么？
2. 成交量很大，是否自动意味着很多人看涨？想一想：每一笔成交同时有买方和卖方。
3. 如果市场已经普遍预期一条好消息，消息真正公布后价格还会不会下跌？请用“预期差”解释。

## 本课核心要点

1. 股票价格来自买卖双方持续报价和成交，不是固定的公司标签。
2. 公司经营、外部环境和市场情绪都会改变人们对未来的预期，进而改变报价。
3. 公司价值与市场价格相关但不相等；短期涨跌本身不是投资结论。
4. 先记录可验证的事实，再区分解释和预测。
