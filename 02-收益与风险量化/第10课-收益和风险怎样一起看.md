# 第 10 课：收益和风险怎样一起看？

> **本课只解决的问题**：面对两段历史结果，为什么不能只选收益率更高的一段？  
> **预计时间**：45–60 分钟。  
> **本课不做什么**：不建立产品评分或排名，不用公式挑选“最佳资产”。

> **本课行动边界**  
> - 只比较虚构情景，比较结果不构成任何产品选择。  
> - 收益、波动和回撤是互补信息，不存在一个指标能替代全部判断。  
> - 你的资金期限和回撤承受力优先于收益排序。

## 先做：比较三段不完整但有用的信息

在表格中输入以下虚构数据。它们只用于练习比较结构，不代表真实资产；三组参数也不应被理解为任何指数、基金或债券产品的历史承诺。

| 情景 | 三年年化收益率 | 年化波动率 | 最大回撤 | 你的直观判断 |
| --- | ---: | ---: | ---: | --- |
| A | 7% | 15% | -22% |  |
| B | 12% | 25% | -45% |  |
| C | 4% | 4% | -8% |  |

先不许写“B 最好”，只写下每行的事实：谁的历史年化高、谁的起伏更大、谁曾出现更深下跌。

## 三个指标分别回答什么

- **收益率**：在一个明确期间内，期末相对期初变化多少。
- **波动率**：期间内收益率日常起伏有多分散。
- **最大回撤**：从某次历史高点到之后低点，最深跌了多少。

它们对应三种不同问题：结果怎样、过程有多摇晃、最痛的一次下跌多深。把它们合成一个“好／坏”结论，会丢失重要信息。

情景 B 的年化收益更高，但它的最大回撤也显著更深。若一个人在 -20% 时大概率退出，B 的历史高收益对他未必可以实现。情景 C 的波动和回撤小，也不说明它天然更适合；若资金需要长期增长，它的回报是否足够仍要结合通胀和目标判断。

## 不要急着造一个万能分数

你会看到类似“收益除以波动”的风险调整收益指标。它们有价值，但都依赖数据期间、无风险收益假设、分布特征和可持续性等条件。对零基础阶段而言，先把原始事实并列出来，比把它们压缩成一个看似精确的分数更可靠。

正确的比较顺序是：

```text
先确认是否同一期间、同一货币、同一收益口径
→ 再并列收益、波动与回撤
→ 再问这条路径是否符合资金期限和个人承受力
→ 最后才研究产品本身与成本
```

这是一套提问流程，不是买卖公式。

## 再做：写出有条件的比较结论

对 A、B、C 三个情景各写一句结论，格式必须包含“历史上”“在这三项数据里”与“仍需确认”。

示例结构：

```text
在这三项历史数据里，B 的年化收益较高，但波动和最大回撤也更大；
仍需确认数据期间、产品性质、费用和我能否承受类似下跌。
```

然后补充你的个人约束：如果回撤接近或超过 -20%，你希望未来的配置方案如何处理？此处只记录问题，不制定买卖动作。

## 检查理解

1. 为什么收益率最高的情景不一定是对你最合适的情景？
2. 波动率较低与最大回撤较小，是否总是同时发生？
3. 比较不同产品历史表现前，至少要统一哪三项口径？

## 核心要点

1. 收益、波动和回撤分别描述结果、日常起伏和最深下跌。
2. 指标要并列阅读，不能用单一排名替代个人约束。
3. 数据口径、资金期限和可承受回撤是比较的前提。
