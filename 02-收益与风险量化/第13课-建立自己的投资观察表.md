# 第 13 课：建立自己的投资观察表

> **本课只解决的问题**：怎样把收益、波动、回撤和现金流放在同一张表中，用于长期复盘而不是预测？  
> **预计时间**：60–90 分钟。  
> **本课不做什么**：不生成买卖信号，不建立收益目标，也不制定真实配置方案。

> **本课行动边界**  
> - 本表是学习与复盘工具，不是自动决策系统。  
> - 任何空白、未知或不可比较的数据，应如实保留为空白。  
> - 后续资产配置必须先处理应急资金、期限与风险承受力，再使用本表。

## 先做：建立一张只记录事实的表

创建一个名为“投资观察表”的工作表，先建立四个区域。

### 区域一：资金边界

| 项目 | 当前记录 | 说明 |
| --- | --- | --- |
| 应急资金是否已预留 | 是／否 | 目标为至少覆盖 3–6 个月必要生活支出，并与长期投资资金分开 |
| 应急资金存放位置 |  | 应具备随时可用、低波动的特点；具体产品放到后续资产课程讨论 |
| 近期目标资金 |  | 记录 1–3 年内明确需要使用的金额与用途 |
| 可长期投资部分 |  | 在应急资金与近期目标资金之外，才进入后续配置讨论 |
| 每月可长期投入上限 | 3,000–4,000 元 | 上限不是强制投入额 |
| 可承受的短期账面下跌 | 约 -20% | 焦虑阈值，不是市场预测 |

### 区域二：观察对象和数据口径

| 观察对象 | 数据期间 | 价格／净值来源 | 是否一次投入 | 是否包含新增资金 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

没有期间和口径的数据，不进入后续比较。

### 区域三：结果与路径

| 累计收益率 | 年化收益率 | 日波动率 | 最大回撤 | 通胀后的实际收益 | 我能确认的事实 |
| ---: | ---: | ---: | ---: | ---: | --- |
|  |  |  |  |  |  |

### 区域四：待确认问题

| 我看到的数字 | 它没有告诉我的事 | 我需要查证的来源 | 何时复盘 |
| --- | --- | --- | --- |
|  |  |  |  |

复盘优先按季度或半年进行，避免每天、每周追随短期波动。出现以下情况时再做一次触发复盘：账户或观察对象回撤接近个人约 -20% 阈值、收入或支出发生明显变化、家庭责任或资金目标调整，或市场出现影响自身计划的极端事件。复盘的目标是核对资金边界和假设，不是临时预测涨跌。

## 这张表怎样避免误导你

表中任何一个指标都应该伴随“它没有告诉我的事”。例如：

- 年化收益没有告诉你中间跌幅与持有体验；
- 波动率没有告诉你是否能在需要用钱时卖出；
- 最大回撤没有告诉你未来下跌上限；
- 平均成本没有告诉你资产未来值不值得持有；
- 实际收益没有告诉你具体家庭支出的全部变化。

这使表格从“找一个更好看的数字”转为“发现还缺什么证据”。长期投资能力的核心不是一次填满表，而是在新信息出现后持续修正判断。

## 再做：填一行虚构记录

使用前几课的任意一组虚构数据，填入完整的一行。若某项还不会算，直接填“待补”，并在最后一区域写出你缺少的是数据、公式还是概念。

然后写一句结论，必须使用下面的格式：

```text
在 [数据期间] 的 [数据口径] 下，我观察到 [事实]；
这不足以说明 [不能推出的结论]；下一步我需要确认 [具体问题]。
```

示例：在三年、一次投入的虚构数据下，我观察到年化收益 8%、最大回撤 -15%；这不足以说明未来仍会获得 8% 收益；下一步需要确认资产类型、费用和持仓风险。

## 检查理解

1. 为什么“观察对象”后必须记录数据期间和是否追加资金？
2. 为什么表格中允许出现“待补”和空白？
3. 如果一项历史结果超过你的回撤承受力，应优先补什么信息，而不是立刻做什么？

## 核心要点

1. 好的观察表先固定资金边界和数据口径，再记录收益与风险指标。
2. 每个数字都应附带它不能说明的事情，防止指标被过度解释。
3. 复盘的目标是改进问题与证据，而不是追逐预测正确。

## 下一步行动

**完成标志**：

- [ ] 我已建立包含资金边界、数据口径、指标与待确认问题的观察表。
- [ ] 我已用虚构数据完整填入至少一行。
- [ ] 我能写出“事实、不能推出的结论、待确认问题”三段式记录。

**此刻不要做**：

- 不要把观察表中的历史数字转化成自动买卖信号。
- 不要在应急资金和短期目标尚未厘清时写真实配置方案。
- 不要因表格算得完整，就忽略产品本身、费用与合规风险。
