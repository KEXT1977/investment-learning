# 第 08 课：波动率在说什么？

> 账户净值每天上下跳动时，单看某一天的涨跌，很难说清整套记录有多颠簸。这一课我们把价格序列换算成每天的收益率，再用波动率读出它整体的起伏程度。

## 从价格变成每天的变化率

先有一串虚构的收盘价，代表连续 11 个交易日的价格：

| 日期序号 | 收盘价 |
| ---: | ---: |
| 1 | 100 |
| 2 | 102 |
| 3 | 99 |
| 4 | 101 |
| 5 | 98 |
| 6 | 100 |
| 7 | 103 |
| 8 | 101 |
| 9 | 104 |
| 10 | 102 |
| 11 | 103 |

要描述这组价格的颠簸程度，我们不能直接看价差，而要看**每天都收益率**——也就是今天的价格相对昨天变化了多少比例。每天的收益率是：

```text
当日收益率 = (今日收盘价 / 昨日收盘价) − 1
```

譬如第 2 天：102 / 100 − 1 = 2%。第 3 天：99 / 102 − 1 ≈ −2.94%。用比例而不是绝对价差，是因为涨跌 1 元对 10 元和 100 元的资产含义完全不同——收益率把尺度归一了，才能放进同一套统计里。

## 波动率：收益率围绕平均值有多散

把 11 天的日收益率算出来以后，它们有时 +2%、有时 −3%、有时 +1%。**波动率**描述的就是：这些收益率上下起伏的程度。起伏越不稳定、偏离平均越远，波动率通常越高。白话来说，它是一把量尺，量的是这套收益率“平时离自己的平均值有多远”。

在 Excel 或 WPS 里，对这段日收益率区域（从第 2 天到第 11 天）使用：

```text
=STDEV.S(日收益率区域)
```

`STDEV.S` 是样本标准差函数，用来根据有限天数的观察，估计这些收益率通常偏离平均值多远。结果是百分比。（你暂时不必推导标准差公式；先知道它衡量“每天收益率通常离平均值多远”就够用了。）用上面的虚构数据算下来，日波动率约在 1.8% 附近——这意味着这些天里，大多数单日收益率落在日平均收益上下约 1.8 个百分点的范围内。

如果要把它粗略换算成“年化波动率”，常见写法是：

```text
年化波动率 ≈ 日波动率 × SQRT(252)
```

其中 252 约等于一年常见的交易日数，`SQRT` 是开方。以刚才约 1.8% 的日波动率为例，乘以 √252 ≈ 15.9，年化波动率约在 28% 上下。请务必明白，这个换算是建立在不少简化假设上的，只能当作“把不同时间尺度近似翻译一下”，**不能**理解成“全年最多可能涨或跌这么多”。单日极端跌幅可能远超通常波动范围，全年最深的坑也不是年化波动率能预测的——那是下一课最大回撤的领地。

## 波动率看不见的那些事

波动率描述的是收益率有多分散，它不直接等于“会亏多少钱”，也没法告诉你最大的那一次下跌。举个例子，两条从 100 出发、结束都在 110 的路径：

- 路径甲：每天涨跌都很小，一路平稳摸到 110；
- 路径乙：先跌到 80，再一路涨回 110。

两者的期末收益都是 10%，但路径乙的每日变化显然更剧烈，波动率也可能更高，持有途中也更容易让人想放弃。期末金额只是结果的一张照片，波动率开始描述过程摇晃的程度。

为了看波动率真的会区分“摇”和“稳”，我们再放一组故意很颠簸的虚构价格作对照：

| 日期序号 | 收盘价 |
| ---: | ---: |
| 1 | 100 |
| 2 | 95 |
| 3 | 102 |
| 4 | 88 |
| 5 | 98 |
| 6 | 91 |
| 7 | 105 |
| 8 | 96 |
| 9 | 108 |
| 10 | 101 |
| 11 | 110 |

这组同样起点 100、终点 110，期末收益同为 10%，但日收益率明显更散，`STDEV.S` 算出来的波动率会明显高于前面的平稳组。两组都上涨，体验却天差地别——这正是波动率的意义。

还要提醒一句：**波动高不等于必然差，波动低也不等于没有风险**。有些资产平时价格变化很小、波动率很低，却可能在特殊情况下面临无法及时卖出的风险。另有第三组极致平稳的虚构价格可以自己算一算：100、101、102、102、103、103、104、105、105、106、107。它同样是上涨、同样起点终点，但日波动率会低得多。把这些都算出来，你就明白：波动率是在帮你提问——这条曲线有多晃，我扛不扛得住——而不是替你做买卖决定。

那么，当一条曲线晃到让人想离场时，最痛的那一刻往往不是整体波动，而是从高点一头栽下来的那段路。下一课，我们用最大回撤这个指标，专门去测那次最深的下坠：[第 09 课：最大回撤如何衡量下跌](第09课-最大回撤如何衡量下跌.md)。
