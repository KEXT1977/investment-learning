# 第 08 课：波动率在说什么？

> **本课只解决的问题**：一串每天不同的涨跌，怎样用一个数字描述它的起伏程度？  
> **预计时间**：60–75 分钟。  
> **本课不做什么**：不根据波动率预测明天涨跌，也不建立自动买卖规则。

> **本课行动边界**  
> - 只处理少量历史或虚构数据，不将统计结果视为交易信号。  
> - 波动率反映过去样本的离散程度，不能保证未来风险范围。  
> - 单一指标不能替代资金用途、回撤承受力和产品风险判断。

## 先做：从价格变成每天的变化率

在表格的 A 列输入 11 个连续交易日的收盘价。可以使用下面的虚构数据：

| 日期序号 | 收盘价 |
| ---: | ---: |
| 1 | 100 |
| 2 | 102 |
| 3 | 99 |
| 4 | 101 |
| 5 | 98 |
| 6 | 100 |
| 7 | 103 |
| 8 | 101 |
| 9 | 104 |
| 10 | 102 |
| 11 | 103 |

在 C3 输入每日收益率公式，再向下填充：

```text
=(B3 / B2) - 1
```

把 C 列设置为百分比。不要直接对价格做“平均涨跌”判断；同样是上涨 1 元，对 10 元和 100 元资产的含义不同，所以波动通常从收益率序列开始计算。

## 波动率：收益率围绕平均值有多分散

**波动率**可以先理解为：一段时间内收益率上下起伏的程度。起伏越不稳定，波动率通常越高。

在 Excel 或 WPS 中，对刚才的日收益率区域使用：

```text
=STDEV.S(C3:C12)
```

`STDEV.S` 是样本标准差函数，用于根据有限天数的观察值估计离散程度。结果请设置为百分比。这里不必先推导标准差公式；你只需知道它衡量的是每一天的收益率通常离平均值有多远。

如果你需要把日波动率做成粗略年化估计，常见写法是：

```text
=日波动率 * SQRT(252)
```

其中 252 约代表常见年度交易日数。这个换算建立在很多简化假设上，初学时只把它当作“不同时间尺度的近似翻译”，不要把结果理解为全年最大可能涨跌幅。

波动率描述的是收益率的分散程度，不是最大损失。极端情况下，单日跌幅可能远超通常波动范围；年化波动率也不能告诉你全年最多亏多少。最大回撤要单独从历史高点计算，下一课会处理。

## 同样期末收益，不同过程

比较两条虚构路径：

- 路径甲：每天变化很小，最后从 100 到 110；
- 路径乙：先跌到 80，再涨到 110。

它们的期末收益都为 10%，但路径乙的每日变化通常更剧烈，波动率可能更高，也更容易让人在中途放弃。期末金额是结果的一张照片；波动率开始描述过程的摇晃程度。

再建立一组波动更剧烈的虚构价格，作为对照：

| 日期序号 | 收盘价 |
| ---: | ---: |
| 1 | 100 |
| 2 | 95 |
| 3 | 102 |
| 4 | 88 |
| 5 | 98 |
| 6 | 91 |
| 7 | 105 |
| 8 | 96 |
| 9 | 108 |
| 10 | 101 |
| 11 | 110 |

分别计算两组数据的日收益率和 `STDEV.S`，不要因为两组最终都上涨就忽略中间过程的差异。

波动高不等于必然差，波动低也不等于没有风险。例如，某些资产平时价格变化很小，却可能在特殊情况下出现无法及时卖出的风险。指标只能帮助你提问，不能替你做结论。

## 检查理解

1. 为什么计算波动率时通常使用每日收益率，而不是直接使用每日价格？
2. 波动率较高，能否推出未来一定亏损更多？为什么？
3. 两个资产期末收益相同，为什么仍需要比较中间过程？

## 核心要点

1. 波动率描述一段历史中收益率的起伏程度，而非收益高低。
2. 它基于过去样本，不能预测未来，也不能代表所有风险。
3. 同样的期末收益，可能伴随截然不同的持有体验。
